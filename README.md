# Imersão DEV - Alura (9ª Edição - 2025)

Projeto criado durante a Imersão DEV da Alura (9ª edição - 2025), com o objetivo de praticar conceitos de HTML, CSS e JavaScript de forma interativa. A cada aula, foi desenvolvido um miniaplicativo diferente, com foco em lógica de programação e interatividade com o usuário.

## 🔨 Funcionalidades do Projeto

- Conversor de moeda simples (Dólar para Euro)
- Jogo Pedra, Papel ou Tesoura com validação de idade
- Desafio inspirado em jogos de sobrevivência (escolha de vidros)
- Cabo de guerra entre personagens e vilões com valores aleatórios
- Quiz interativo de perguntas e respostas sobre temas gerais

## ✔️ Técnicas e Tecnologias Utilizadas

- HTML5
- CSS3 (via arquivo externo `style.css`, compartilhado entre os projetos)
- JavaScript Puro (DOM, eventos, lógica condicional, laços e arrays)

    - `index.html`: Conversor de moedas

## 🛠️ Abrir e rodar o projeto

Para iniciar o projeto localmente, siga os passos abaixo:

1. **Certifique-se de que o Node.js está instalado**:
    - O [Node.js](https://nodejs.org/) é necessário para rodar o projeto. Você pode verificar se já o tem instalado com:

      ```bash
      node -v
      ```

    - Se não estiver instalado, baixe e instale a versão recomendada.

2. **Clone o Repositório**:
    - Copie a URL do repositório e execute o comando abaixo no terminal:

      ```bash
      git clone <URL_DO_REPOSITORIO>
      ```

3. **Acesse a pasta do projeto e abra os arquivos desejados**:
    - Cada aula está em uma subpasta. Basta abrir o arquivo `index.html` correspondente no navegador.

## 🌐 Deploy

Por se tratar de um projeto com HTML estático, você pode publicá-lo facilmente usando o [GitHub Pages](https://pages.github.com/):

1. No GitHub, crie um repositório e envie o conteúdo do projeto para ele.
2. Acesse a aba **Settings** (Configurações) do repositório.
3. Clique em **Pages** no menu lateral.
4. Selecione a branch (geralmente `main`) e a pasta raiz ("/root").
5. Clique em **Save**.
6. Seu projeto estará acessível em: `https://seu-usuario.github.io/nome-do-repositorio`
