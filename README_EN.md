# Imersão DEV - Alura (9th Edition - 2025)

Project created during the Imersão DEV by Alura (9th edition - 2025), with the goal of practicing HTML, CSS, and JavaScript concepts in an interactive way. In each lesson, a different mini-application was developed, focusing on programming logic and user interactivity.

## 🔨 Project Features

- Simple currency converter (Dollar to Euro)
- Rock, Paper, Scissors game with age validation
- Survival challenge inspired game (glass selection)
- Tug-of-war game between characters and villains with random strength values
- Interactive quiz with general knowledge questions

## ✔️ Techniques and Technologies Used

- HTML5
- CSS3 (via external `style.css`, shared between all projects)
- Pure JavaScript (DOM, events, conditional logic, loops, and arrays)

## 📁 Project Structure

- **Aula 1/**
    - `index.html`: Currency converter (Dollar to Euro)
    - `jogo1.js`: Conversion logic (Dollar to Euro)
- **Aula 2/**
    - `index.html`: Rock, Paper, Scissors game with age validation
    - `jogo2.js`: Game logic
- **Aula 3/**
    - `index.html`: Glass Challenge
    - `jogo3.js`: Random choice and luck simulation
- **Aula 4/**
    - `index.html`: Força ou Queda - Tug of War
    - `jogo4.js`: Arrays with characters and villains, strength calculation
- **Aula 5/**
    - `index.html`: Interactive quiz
    - `jogo5.js`: Dynamic DOM-based questions and answers

## 🛠️ Running the Project

To run the project locally, follow the steps below:

1. **Ensure Node.js is installed**:
    - [Node.js](https://nodejs.org/) is required to run the project. You can check if you have it installed by running:

      ```bash
      node -v
      ```

    - If it's not installed, download and install the recommended version.

2. **Clone the Repository**:
    - Copy the repository URL and run the following command in the terminal:

      ```bash
      git clone <REPOSITORY_URL>
      ```

3. **Access the project folder and open the desired files**:
    - Each lesson is inside a subfolder. Simply open the corresponding `index.html` file in your browser.

## 🌐 Deploy

Since this is a static HTML project, you can easily publish it using [GitHub Pages](https://pages.github.com/):

1. On GitHub, create a repository and upload the project files.
2. Go to the **Settings** tab of the repository.
3. Click on **Pages** in the sidebar.
4. Select the branch (usually `main`) and the root folder ("/root").
5. Click **Save**.
6. Your project will be accessible at: `https://your-username.github.io/repository-name`
