# Alura DEV Immersion (9th Edition - 2025)

This project was created during Alura's DEV Immersion (9th edition - 2025), aiming to practice HTML, CSS, and JavaScript concepts in an interactive and engaging way. In each lesson, a different mini-application was developed, focusing on programming logic and user interaction.

## 🔨 Project Features

- Simple currency converter (Dollar to Euro)
- Rock, Paper, Scissors game with age validation
- Survival game challenge (glass panel selection)
- Tug of war between characters and villains with random values
- Interactive general knowledge quiz

## 🛠️ How to Run the Project Locally

To run the project on your machine, follow the steps below:

1. **Make sure Node.js is installed**:
    - [Node.js](https://nodejs.org/) is required to run certain parts of the project. Check if it’s already installed by running:

      ```bash
      node -v
      ```

    - If it’s not installed, download and install the recommended version.

2. **Clone the Repository**:
    - Copy the repository URL and run the command below in your terminal:

      ```bash
      git clone <REPOSITORY_URL>
      ```

3. **Access the project folder and open the desired lesson**:
    - Each lesson is in its own subfolder. Just open the corresponding `index.html` file in your browser.

## 🌐 Deploy

Since this is a static HTML project, it can be easily published using [GitHub Pages](https://pages.github.com/):

1. Create a repository and push your project files to it.
2. Go to the **Settings** tab of your repository.
3. Click on **Pages** in the side menu.
4. Select the branch (usually `main`) and the root folder (`/root`).
5. Click **Save**.
6. Your project will be available at:  
   `https://your-username.github.io/your-repository-name`
